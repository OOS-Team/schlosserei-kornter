# Schlosserei Kornter – Website

Moderne Unternehmenswebsite der **Kornter Schlosserei GmbH** (Heilbronn).

## Live

**GitHub Pages:** https://oos-team.github.io/schlosserei-kornter/

## Lokal starten

```bash
npx serve .
```

## Inhalt

- Responsive One-Pager (Leistungen, Referenzen, Über uns, Kontakt)
- Offizielles Logo & Projektfotos
- Impressum & Datenschutz

## Tech

Statisches HTML/CSS/JS – kein Build nötig. Deploy über GitHub Pages (Workflow `.github/workflows/pages.yml`).
